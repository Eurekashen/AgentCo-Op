## Decisions (fixed before any run; reasons in findings.md)

- Vocabulary: populations ("all",); groups TB, LTBI, HC, OD, autoimmune, bacterial,
  paediatric_control; claim contrasts (TB, LTBI), (TB, HC), (TB, OD); scope contrasts
  (autoimmune, HC) and (bacterial, paediatric_control) at S4, (TB, OD) wherever OD is held.
- Site files: TSV matrix, first column = the platform's native feature id (ILMN_ ids; Agilent
  feature numbers), one column per sample with an opaque token (no GSM ids); one sample per
  donor. S1 = GSE19439 ∪ GSE19444 (same platform, same lab; probes in both). S2 = GSE37250
  region South Africa. S6 = GSE28623. S4 = GSE22098 adult autoimmune stratum (Still, ASLE + their
  controls) and paediatric bacterial stratum (Staph, Strep + "Strep and Staph" controls); pSLE
  and its controls dropped.
- Site cards: native condition text from GEO (`source_name` / `characteristics`) as opaque codes
  with a site codebook; covariates whitelisted (sex, age where given, HIV status at S2); platform
  stated; the platform's GEO annot table copied into the workspace as the mapping resource.
- Scope table and rule exactly as §5.2 (AUC thresholds 0.65 / 0.70, bacterial demotion margin
  0.15), in `cases/tb.py`.
- Held-out (eval side only, `data/hidden/tb/`): GSE73408 TB vs pneumonia / LTBI, GSE89403 TB vs
  healthy (baseline visit, technical replicates summed), GSE101705 TB vs LTBI; per cohort per-gene
  rank-to-normal, score = mean(up) − mean(down), AUC per contrast; exclusion table of shared
  patients / SuperSeries written with the reference hash.

## Tasks

1. `agentcoop/cases/tb.py`: parse series matrices (no code from downloads is executed; files are
   read as data), build the four site files + cards + `public/task.json` under
   `data/tasks/tb/tb-min/`, `load_case`, scope table/rule. Boundary test: site files carry only
   the whitelisted columns; no GSM ids, no disease text outside the codebook. `tests/test_tb.py`
   on a toy series matrix.
2. `agentcoop/eval/tb.py`: held-out cohorts → `data/hidden/tb/` (+ sha256 in a committed
   manifest), scoring rule, endpoints (a) scope-label correctness where ours ≠ S2-alone,
   (b) top-5 signature AUC on GSE73408 TB vs pneumonia; secondary AUCs.
3. Headroom gate for TB ($0): (i) S2 alone, (ii) MA-tools over the federation, (iii) S2 with
   S4-based pruning; targets S5 Bloom and S3 Malawi; pass rule written into findings.md before
   computing.
4. Two-claim dry run of the protocol on the TB sites with fixed claims ($0), then one draw of
   ours + S2-alone; then the full arm set (3 draws) after the freeze.
